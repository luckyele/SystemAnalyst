## 一、操作系统

### 1.1 进程管理

| 考点           | 结论                                                          |
| ------------ | ----------------------------------------------------------- |
| **进程 vs 线程** | 进程是**资源分配的基本单位**，线程是**CPU 调度的基本单位**；线程共享进程的地址空间与资源，只独享栈与寄存器 |
| **三态模型**     | 运行 ↔ 就绪 ↔ 阻塞；**运行→阻塞是主动的**（等待 I/O），**阻塞→就绪是被动的**（I/O 完成）    |
| **五态模型**     | 三态 + 新建态 + 终止态；另有**挂起**（静止就绪 / 静止阻塞，进程被换出到外存）               |
| **进程通信 IPC** | 共享内存（最快）、消息传递、管道、信号量、套接字 Socket                             |
| **同步与互斥**    | 临界区、信号量（P/V 原语）、管程；互斥信号量初值通常为 1，同步信号量初值为资源数                 |

**调度算法对比**：

| 算法              | 特点                             | 是否抢占        | 问题                     |
| --------------- | ------------------------------ | ----------- | ---------------------- |
| 先来先服务 FCFS      | 简单公平                           | 否           | 长作业导致短作业等待（**不利于短作业**） |
| 短作业优先 SJF/SPF   | 平均周转时间最短（理论最优）                 | 否/可抢占（SRTN） | **长作业饥饿**              |
| 优先级调度           | 按优先级                           | 可/否         | 低优先级饥饿（用**老化**缓解）      |
| 时间片轮转 RR        | 公平、响应快，适合分时                    | **是**       | 时间片过小切换开销大             |
| **高响应比优先 HRRN** | 响应比 = **(等待时间 + 服务时间) / 服务时间** | 否           | 兼顾长短作业                 |
| 多级反馈队列          | 综合最优，折中                        | 是           | 最复杂                    |

**死锁**：

- **四个必要条件**：**互斥、请求与保持（占有且等待）、不可剥夺（不可抢占）、环路等待**——四个条件**同时成立**才可能死锁。
- **四种处理**：**预防**（破坏四个条件之一）、**避免**（**银行家算法**，动态检查资源分配后系统是否仍处安全状态）、**检测**（资源分配图简化）、**解除**（撤销进程 / 资源剥夺）。
- 资源分配图中：若能完全化简则**无死锁**。

### 1.2 存储管理

| 方式      | 单位            | 是否连续    | 碎片                    |
| ------- | ------------- | ------- | --------------------- |
| **分页**  | 页（固定大小，如 4KB） | 物理块可不连续 | 只有**内部碎片**（页内浪费，平均半页） |
| **分段**  | 段（大小可变，按逻辑单位） | —       | **外部碎片**              |
| **段页式** | 先分段再分页        | —       | 结合两者                  |

**地址变换**：逻辑地址 = 页号 + 页内偏移；查页表得物理块号；物理地址 = 块号 × 页大小 + 页内偏移。**快表（TLB）**&#x7528;于加速查表。

**页面置换算法**：

| 算法            | 特点                                       |
| ------------- | ---------------------------------------- |
| **OPT 最佳**    | 淘汰永不再用或最长时间后使用的页；**理论最优，无法实现，用作基准**      |
| **FIFO**      | 先进先出；**存在 Belady 异常（分配的物理块增加，缺页次数反而上升）** |
| **LRU 最近最少用** | 淘汰最久未访问；性能好，需硬件支持；**无 Belady 异常**        |
| LFU           | 淘汰访问次数最少                                 |
| Clock（NRU）    | 近似 LRU，用访问位循环扫描                          |

> **必背**：**只有 FIFO 会产生 Belady 异常**；**抖动/颠簸 = 频繁页面换入换出**，根因是**分配的物理块数不足**。

### 1.3 设备与磁盘管理

**I/O 控制方式（CPU 干预程度递减）**：**程序查询（轮询）→ 中断驱动 → DMA（直接存储器存取）→ 通道（I/O 处理器）**。

- **DMA**：数据传送以**块**为单位，仅在传送开始与结束时需 CPU 干预；中断方式以字/字节为单位。
- **SPOOLing（假脱机）**：把**独占设备改造为共享设备**（典型：打印机），用磁盘做输入井/输出井。

**磁盘调度算法**：FCFS → **SSTF 最短寻道时间优先**（会饥饿）→ **SCAN 电梯算法**（双向移动，到端点折返）→ **CSCAN 循环扫描**（单向，回到起点重新扫描，响应更均匀）。

**磁盘访问时间 = 寻道时间 + 旋转延迟（等待扇区转到磁头下） + 传输时间**。

**位示图计算**：物理块总数 = 磁盘容量 ÷ 块大小；位示图占用位数 = 块总数（1 位对应 1 块）；占用字节数 = 块总数 ÷ 8。

### 1.4 文件系统

- **索引节点 inode**：文件描述信息与文件名分离，目录项只存文件名 + inode 号；
- **空闲空间管理**：空闲表法、空闲链表法、**位示图法**、**成组链接法**（UNIX）；
- 文件共享：**硬链接**（多个目录项指向同一 inode，删除需链接计数归零）与**符号链接/软链接**（存路径，源文件删除后失效）。

## 二、计算机网络

### 2.1 体系结构（必背对应关系）

| OSI 七层    | 功能             | 协议 / 设备                            | PDU              |
| --------- | -------------- | ---------------------------------- | ---------------- |
| **应用层**   | 用户接口           | HTTP、FTP、SMTP、DNS、Telnet、SNMP、DHCP | 报文 / 数据          |
| **表示层**   | 数据格式转换、加密压缩、编码 | JPEG、ASCII、SSL/TLS（会话表示功能）         | —                |
| **会话层**   | 建立、管理、终止会话     | RPC、SQL、NetBIOS                    | —                |
| **传输层**   | 端到端可靠传输、流量控制   | **TCP、UDP**                        | **段 / 报文段**      |
| **网络层**   | 路由选择与寻址        | **IP、ICMP、ARP、RIP、OSPF、BGP**       | **分组 / 包 / 数据报** |
| **数据链路层** | 成帧、差错控制、介质访问   | Ethernet、PPP、HDLC、VLAN、**交换机、网桥**  | **帧**            |
| **物理层**   | 比特传输           | RS-232、RJ-45、**中继器、集线器 Hub**       | **比特**           |

**TCP/IP 四层**：网络接口层 ↔ 网际层（IP） ↔ 传输层（TCP/UDP） ↔ 应用层（OSI 上三层合并）。

**设备归属（高频）**：**中继器/集线器 = 物理层**；**网桥/交换机 = 数据链路层**；**路由器 = 网络层**；**网关 = 传输层及以上**。

- 集线器：**共享带宽、半双工、冲突域不隔离、广播域不隔离**；
- 交换机：独占带宽、全双工、**隔离冲突域、不隔离广播域**；
- 路由器：**隔离广播域**。

### 2.3 TCP 要点

- **三次握手**：`SYN → SYN+ACK → ACK`（防止已失效的连接请求突然到达）；
- **四次挥手**：`FIN → ACK → FIN → ACK`；**主动关闭方进入 TIME_WAIT，等待 2MSL**（保证最后一个 ACK 能到达、并让本次连接的残余报文在网络中消散）；
- **TCP 首部最小 20 字节**，UDP 首部 **8 字节**，IP 首部最小 20 字节；
- **可靠机制**：校验、序号、确认、超时重传、滑动窗口（**流量控制**）、**拥塞控制**（慢开始、拥塞避免、快重传、快恢复）；
- **TCP vs UDP**：TCP 面向连接、可靠、有序、有流量与拥塞控制，开销大；UDP 无连接、不可靠、无拥塞控制、开销小（适合音视频、DNS 查询、实时游戏）。

### 2.4 IP 与子网划分（计算必考）

| 类别    | 首位范围      | 默认掩码          | 网络位 / 主机位 |
| ----- | --------- | ------------- | --------- |
| **A** | 1 ～ 126   | 255.0.0.0     | 8 / 24    |
| **B** | 128 ～ 191 | 255.255.0.0   | 16 / 16   |
| **C** | 192 ～ 223 | 255.255.255.0 | 24 / 8    |
| D     | 224 ～ 239 | —             | **组播**    |
| E     | 240 ～ 255 | —             | 保留        |

**私有地址（三段，必背）**：**10.0.0.0/8**、**172.16.0.0 ～ 172.31.0.0（/12）**、**192.168.0.0/16**。  
特殊地址：**127.0.0.1 环回**；**169.254.x.x 自动专用（APIPA，DHCP 失败）**；**0.0.0.0 本网络 / 默认路由**；**255.255.255.255 受限广播**。

**子网划分公式**：

```
借位 s 位划分子网  →  子网数 = 2^s        （CIDR 下不再减 2，传统教材减 2 需注意题干口径）
剩余主机位 r 位     →  每个子网可用主机数 = 2^r − 2   （减网络地址与广播地址）
子网掩码           →  网络位 + 子网位全 1，主机位全 0
```

**解题三板斧**：

1. 判断是 A/B/C 类 → 得默认网络位；
2. 由掩码或 `/n` 前缀算出**子网位 s** 与**主机位 r**；
3. 用 `2^r − 2` 验证是否满足题目要求的主机数，再用块大小（= 2^r）穷举各子网的网络地址与广播地址。

**其他**：**CIDR 无类域间路由**、**路由聚合（超网）**&#x53D6;最长共同前缀；**IPv6 地址 128 位**，8 段十六进制，**无广播**（用组播与任播替代），过渡技术：**双栈、隧道、NAT64/协议翻译**。

### 2.5 应用层与新技术

- **DNS**：递归查询（客户机→本地 DNS 服务器）与迭代查询（本地服务器→各级域服务器）；记录类型：**A（IPv4）、AAAA（IPv6）、CNAME（别名）、MX（邮件交换）、NS（域名服务器）、PTR（反向解析）、TXT**；
- **HTTP 状态码**：**1xx 信息**、**2xx 成功**（200 OK、201 Created、204 No Content）、**3xx 重定向**（301 永久、302 临时、304 未修改走缓存）、**4xx 客户端错误**（400 请求错误、401 未认证、403 禁止、404 未找到）、**5xx 服务器错误**（500 内部错误、502 网关错误、503 服务不可用）；
- **HTTP 演进**：1.1 持久连接与管道化 → **2.0 多路复用、二进制分帧、头部压缩、服务端推送** → **3.0 基于 QUIC/UDP**，解决队头阻塞；
- **GET vs POST**：GET 参数在 URL、有长度限制、可被缓存与收藏、幂等；POST 在请求体、无长度限制、不缓存、非幂等；
- **邮件协议**：**SMTP 发送（25）**，**POP3（110）/ IMAP（143）接收**；IMAP 支持在服务器上管理邮件（多设备同步），POP3 下载到本地；
- **无线与物联网**：**Wi-Fi 6 = 802.11ax**；**蓝牙**（短距离、低功耗）、**ZigBee**（低速率、自组网、工业与家居）、**NFC**（近场，<10cm）、**LoRa / NB-IoT**（低功耗广域网 LPWAN）；
- **5G 三大应用场景**：**eMBB 增强移动宽带**、**URLLC 超可靠低时延通信**、**mMTC 海量机器类通信**；
- **其他**：NAT（缓解地址枯竭）、VPN（虚拟专用网）、CDN（内容分发网络，就近访问、减轻源站压力）。

## 三、计算机组成与体系结构

### 3.1 必会计算

| 计算项              | 公式                                                               |
| ---------------- | ---------------------------------------------------------------- |
| **Cache 平均访问时间** | **T = H × Tc + (1 − H) × Tm**（H 命中率，Tc Cache 时间，Tm 主存时间）         |
| **流水线执行时间**      | **T = (k + n − 1) × Δt**（k = 段数，n = 指令条数，Δt = 流水线周期 = **最长段耗时**） |
| 流水线吞吐率           | **TP = n / T**                                                   |
| 流水线加速比           | **S = 顺序执行时间 / 流水线执行时间 = (n × k × Δt) / T**（极限趋近 k）              |
| 流水线效率            | **E = 加速比 / 段数 k**                                               |
| **海明校验码**        | 校验位 **k** 满足 **2^k ≥ m + k + 1**（m 为数据位数）                        |
| CRC 循环冗余校验       | 用**生成多项式**做**模 2 除法**，余数作为校验位（检错能力强，广泛用于数据链路层）                   |

### 3.2 必辨概念

- **Flynn 分类**：**SISD**（单指令单数据流，传统单处理器）、**SIMD**（单指令多数据流，向量处理/GPU）、**MISD**（多指令单数据流，少见）、**MIMD**（多指令多数据流，多处理器/多核）；
- **CISC vs RISC**：CISC 指令多、长度可变、微程序控制（x86）；RISC 指令少而规整、定长、硬布线、**大量通用寄存器、流水线友好、编译优化**（ARM、MIPS、RISC-V）；
- **Cache 映射**：**直接映射**（固定位置，冲突多、实现简单）、**全相联**（任意位置，冲突少、成本高）、**组相联**（折中，最常用）；
- **Cache 写策略**：写直达（Write Through，同时写主存）与写回（Write Back，仅换出时写主存）；
- **寻址方式**：立即、直接、间接、寄存器、寄存器间接、变址、基址、相对；
- **机器数**：**n 位补码范围 −2^(n−1) ～ 2^(n−1) − 1**，补码中 0 唯一，符号位参与运算；**移码**常用于浮点数阶码；
- **IEEE 754 浮点数**：**单精度 32 位**（1 符号 + 8 阶码 + 23 尾数，**阶码偏移 127**）；**双精度 64 位**（1 + 11 + 52，**偏移 1023**）；
- **中断与 DMA**：DMA 以块为单位、不经过 CPU 寄存器，仅在首尾需 CPU 干预。

## 四、数据结构与算法

### 4.1 时间复杂度排序

**O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)**

### 4.2 排序算法（必背表）

| 算法         | 平均             | 最坏                | 最好            | 空间       | **稳定性** |
| ---------- | -------------- | ----------------- | ------------- | -------- | ------- |
| **直接插入排序** | O(n²)          | O(n²)             | **O(n)**（已有序） | O(1)     | ✅ 稳定    |
| **冒泡排序**   | O(n²)          | O(n²)             | **O(n)**      | O(1)     | ✅ 稳定    |
| **简单选择排序** | O(n²)          | O(n²)             | O(n²)         | O(1)     | ❌ 不稳定   |
| **快速排序**   | **O(n log n)** | **O(n²)**（已有序时退化） | O(n log n)    | O(log n) | ❌ 不稳定   |
| **归并排序**   | O(n log n)     | O(n log n)        | O(n log n)    | **O(n)** | ✅ 稳定    |
| **堆排序**    | O(n log n)     | O(n log n)        | O(n log n)    | O(1)     | ❌ 不稳定   |
| 希尔排序       | ≈ O(n^1.3)     | O(n²)             | —             | O(1)     | ❌ 不稳定   |
| **基数排序**   | O(d(n + r))    | O(d(n + r))       | —             | O(r)     | ✅ 稳定    |

> **速记**：**稳定的 = 冒泡、插入、归并、基数**；**不稳定的 = 选择、快排、堆排、希尔**；**最坏仍是 O(n log n) 的 = 归并、堆排**。

### 4.3 树与图

**二叉树性质**：

- 第 i 层最多 **2^(i−1)** 个结点；深度为 k 的二叉树最多 **2^k − 1** 个结点；
- **n₀ = n₂ + 1**（叶子数 = 度为 2 的结点数 + 1）；
- 有 n 个结点的**完全二叉树**深度 = **⌊log₂n⌋ + 1**；
- 完全二叉树按层序编号 i：左孩子 **2i**，右孩子 **2i+1**，双亲 **⌊i/2⌋**。

| 树              | 要点                                                       |
| -------------- | -------------------------------------------------------- |
| **二叉排序树 BST**  | 左 < 根 < 右；查找效率取决于树高，最坏退化为 O(n)                           |
| **平衡二叉树 AVL**  | 任意结点左右子树高度差（平衡因子）绝对值 ≤ 1，查找/插入/删除 **O(log n)**           |
| **红黑树**        | 近似平衡，插入删除旋转次数少于 AVL，STL/Java TreeMap 使用                  |
| **B 树 / B+ 树** | 多路平衡查找树，**B+ 树所有数据在叶子结点且叶子有链表相连**，适合范围查询——**数据库索引的主流结构** |
| **哈夫曼树**       | **带权路径长度 WPL 最小**，用于**哈夫曼编码（最优前缀编码，无损压缩）**；无度为 1 的结点     |

**图算法**：

- 遍历：**DFS 深度优先**（栈/递归）、**BFS 广度优先**（队列）；
- **最小生成树**：**Prim**（从点出发，适合稠密图）、**Kruskal**（按边权排序 + 并查集，适合稀疏图）；
- **最短路径**：**Dijkstra**（单源，边权非负）、**Floyd**（全源，动态规划）；
- **拓扑排序**（AOV 网，检测是否有环）、**关键路径**（AOE 网，见《项目管理与治理》笔记）；
- **图论公式**：**n 个顶点的完全图边数 = n(n−1)/2**；**欧拉回路**（所有顶点度为偶且连通，边不重复走遍）；**哈密顿回路**（经过每个顶点恰好一次，NP 完全问题）。

### 4.4 算法设计策略

**分治**（快排、归并、二分）｜**动态规划**（最优子结构 + 重叠子问题，如背包、最长公共子序列、Floyd）｜**贪心**（局部最优，如 Prim、Kruskal、Dijkstra、哈夫曼）｜**回溯**（N 皇后、子集树，深度优先 + 剪枝）｜**分支限界**（广度优先/最小代价优先，求最优解）。

## 五、编译原理与程序设计语言

### 5.1 编译六阶段

**词法分析**（输出**记号 token**，识别单词）→ **语法分析**（构造**语法树**，检查句子结构）→ **语义分析**（**类型检查**、符号表、生成中间代码）→ **代码优化**（局部/循环/全局优化，优化在**中间代码**或目标代码上，不改动源程序语义）→ **目标代码生成**。  
**符号表管理**与**出错处理**贯穿全程。

**编译 vs 解释**：编译**生成目标代码**（整体翻译后执行，效率高）；解释**边解释边执行**（不生成目标代码，跨平台、便于调试、效率低）。Java 是**编译 + 解释**混合（编译成字节码 + JVM 解释/JIT 执行）。

### 5.2 文法与自动机（乔姆斯基四型）

| 类型      | 名称           | 对应分析                   | 自动机               |
| ------- | ------------ | ---------------------- | ----------------- |
| **0 型** | 短语结构文法（无限制）  | —                      | 图灵机               |
| **1 型** | 上下文有关文法      | —                      | 线性有界自动机           |
| **2 型** | **上下文无关文法**  | **语法分析**（产生式左部为单个非终结符） | 下推自动机             |
| **3 型** | **正规文法（正则）** | **词法分析**               | **有限自动机 DFA/NFA** |

- **DFA** 是 **NFA** 的特例（DFA 每个状态对某输入只有唯一后继，且无 ε 转移）；
- **NFA 确定化 → DFA → 最小化**；**正规式 ↔ 有限自动机 ↔ 正规文法**三者等价。

**语法分析方法**：

- **自顶向下**：**LL(1)** 文法、递归下降、预测分析表；**必须先消除左递归与回溯**；
- **自底向上**：**算符优先**、**LR(0)、SLR(1)、LR(1)、LALR(1)**（识别能力递增顺序大致为 LR(0) < SLR < LALR < LR(1)）。

**表达式转换**：**前序遍历 = 前缀表达式（波兰式）**；**中序遍历 = 中缀表达式**；**后序遍历 = 后缀表达式（逆波兰式）**。表达式树叶子是操作数，内部结点是运算符。

### 5.3 程序设计语言

- **范型**：命令式/过程式（C、Pascal）、**面向对象**（Java、C++、C#）、**函数式**（Haskell、Scala、Lisp）、**逻辑式/声明式**（Prolog、SQL）；
- **类型系统**：**静态类型**（编译期确定，Java/C）vs **动态类型**（运行期确定，Python/JS）；**强类型**（不允许隐式转换）vs **弱类型**；
- **传参方式**：传值、传引用、传地址（指针）、传名。

## 八、高频计算题清单（考前练手）

1. **Cache 平均访问时间**：H × Tc + (1 − H) × Tm
2. **流水线**：(k + n − 1) × Δt、吞吐率、加速比、效率
3. **海明码校验位数**：求满足 2^k ≥ m + k + 1 的最小 k
4. **CRC**：模 2 除法求余数
5. **子网划分**：子网数 2^s、可用主机数 2^r − 2、网络地址与广播地址
6. **内存分页**：页号与页内偏移的拆分、页面大小与页表项数
7. **位示图**：容量 ÷ 块大小 ÷ 8
8. **磁盘调度**：SSTF / SCAN 下的寻道序列与总移动磁道数
9. **排序与查找**：比较次数、时间复杂度、稳定性判断
10. **二叉树**：结点计数（n₀ = n₂ + 1）、完全二叉树深度、哈夫曼树 WPL
11. **项目管理类**：挣值分析、关键路径、PERT 三点估算、沟通渠道数（见《项目管理与治理考点笔记》）
