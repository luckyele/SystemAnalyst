CHAPTER 01 · 绪论
每年稳定 1～2 题

信息 · 系统 · 系统工程方法论

信息的度量（香农）

信息是不确定性的减少，单位比特（负熵）。

H(x) = − Σ P(xᵢ)·lb P(xᵢ)

概率越小，信息量越大。

信息 11 大特征

客观性、普遍性、无限性、动态性、相对性、依附性、变换性、传递性、层次性、系统性、转化性。

传递性常考：时间上传递=存储，空间上传递=转移/扩散。

系统 9 特性 · 8 原理

9 特性：整体性、层次性、目的性、稳定性、突变性、自组织性、相似性、相关性、环境适应性。

8 原理：整体、整体突变（非加和）、层次、开放、目的、环境互塑共生、秩序、生命周期。

霍尔三维结构（硬系统）

时间维（规划→更新 7 阶段）、逻辑维（问题确定→实施 7 步骤）、知识维。

面向结构化问题，核心是模型化与最优化。

切克兰德（软系统）

面向非结构化问题，核心不是"最优化"而是"比较"，通过学习找出可行满意的结果。

生命周期 · 角色

5 阶段：规划→分析→设计→实现→运行维护；4 原则：高层介入（CIO）、用户参与、自顶向下规划、工程化。

6 大角色，CIO 居金字塔塔尖。

CHAPTER 02 · 数学与工程基础
2～6 分 · "会者不难"

分布 · 图论 · 预测决策 · 线性规划

概率分布与数字特征
二项 E=np，D=np(1−p)
泊松 E = D = λ
均匀 E=(a+b)/2，D=(b−a)²/12
最小生成树

Prim 从点扩展；Kruskal 按边归并。

均得 n−1 条边；各边权值唯一时，最小生成树唯一。

最短路径

Dijkstra（非负权）、Floyd（全源）、Bellman-Ford（负权/负环检测）。

2026 真题A→F 最短路径 = 119。

最大流解题套路

找路径 → 取各段容量最小值（短板）→ 各段扣减、为 0 断边 → 重复至无通路 → 流量求和。

教程例题 ①→⑥ = 10+6+5+1+1 = 23 万吨。

预测与决策
一次指数平滑 ŷ = αy + (1−α)ŷ₋

决策五准则：乐观、悲观、折中系数、等概率、最小后悔值。

线性规划

可行域为凸多边形，最优解必在顶点取得；最优方案的线性组合仍为最优解。

CHAPTER 03 · 计算机系统
8～10 题 · ★★★★★

存储体系 · I/O · 总线 · 可靠性

存储层次

寄存器 → Cache → 主存 → 辅存：按速度递减、容量递增、价格递减组织。

SRAM 做 Cache、DRAM 做主存。

Cache 高频计算
平均周期 t₃ = h·t₁ + (1−h)·t₂

直接 / 全相联 / 组相联映射；淘汰用 LRU；写直达 vs 写回。

I/O 五种方式

程序查询 → 程序中断 → DMA（周期挪用，不经过 CPU）→ 通道 → I/O 处理机，并行度依次提高。

总线带宽
带宽 = 总线宽度 × 频率

例：宽度 4B、2 个时钟周期传一次、10MHz → 4B×10M/2 = 20MB/s。

RAID 与磁盘

RAID 0 条带（无冗余）、1 镜像（利用率 50%）、5 分布式奇偶校验、10 镜像+条带。

可靠性计算（必拿分）
串联 R = R₁ × R₂ × … × Rₙ
并联 R = 1 − (1−R)ⁿ

CHAPTER 04 · 计算机网络
与安全合计 10～12 题

信道极限 · 协议栈 · IP 与分布式

码元与数据速率
码元速率 B = 1/T（波特）
数据速率 R = B · log₂N
奈奎斯特定理（无噪）
R = 2W · log₂N

码元速率上限 = 2 倍带宽。

香农定理（有噪）
C = W · log₂(1 + S/N)

2024 真题2MHz、30dB（S/N=1000）→ C≈20Mbps，先把分贝换算成 S/N。

编码与体系

曼彻斯特（中间跳变，高→低为 1）、差分曼彻斯特、4B/5B。

OSI 七层 vs TCP/IP 四层；TCP 可靠面向连接 vs UDP 高效无连接。

介质访问与 IP

CSMA/CD（有线、先听后发冲突检测）vs CSMA/CA（无线、避免冲突）。

私有地址 10/172.16/192.168 经 NAT 出网；CIDR 子网划分必考计算。

分布式基础

分布式透明性（位置/迁移/复制…）；一致性哈希解决节点伸缩。

CAP：网络分区 P 必选，强一致+故障容忍 → CP，弃 A（2026 考点）。

CHAPTER 05 · 数据库系统（上）
8～10 题 · ★★★★★

三级模式 · 关系代数 · 范式分解

三级模式两级映像

外模式 → 概念模式 → 内模式。

外/概念映像保证逻辑独立性；概念/内映像保证物理独立性。

关系代数

选择 σ（行）、投影 π（列）、连接 ⋈、除 ÷；并差交笛卡尔积。

函数依赖与候选键

Armstrong 公理：自反、增广、传递（导出合并/分解/伪传递）。

用图示法快速找候选键：只出现在左边的属性必在键中。

范式阶梯

1NF（原子性）→ 2NF（消非主属性对键的部分依赖）→ 3NF（消传递依赖）→ BCNF → 4NF（消多值依赖）。

无损分解判定
(R₁∩R₂) → (R₁−R₂)

或

(R₁∩R₂) → (R₂−R₁)
分解两个目标

既要无损连接（可还原），又要保持函数依赖（约束不丢），二者需同时检查。

CHAPTER 05 · 数据库系统（下）
并发控制 · 设计与恢复

事务锁 · E-R 转关系 · SQL 优化 · 备份

事务 ACID

原子性、一致性、隔离性、持久性。

三类不一致：丢失修改、不可重复读、读"脏"数据。

封锁协议

S 锁（读锁）/ X 锁（写锁）；一/二/三级封锁协议逐级解决三类问题。

两段锁协议：扩展段只加锁、收缩段只解锁 → 可串行化。

三类完整性

实体完整性（主键非空唯一）、参照完整性（外键）、用户自定义完整性（域/规则）。

E-R 图转关系模式

1:1 可并入任一端；1:n 联系并入 n 端；m:n 联系必须单独建表。

性能与反规范化

反规范化以空间换时间，用触发器保证冗余数据同步。

SQL 优化：物化视图、复合最左前缀、B+ 树层级升高则索引失效。

备份与恢复

冷备份（停机）/ 热备份（在线）；先写日志（WAL）。

故障恢复：Redo（重做已提交）、Undo（撤销未提交）。

信息化方法 · 战略三阶段 · BSP

企业信息化 5 种方法

IRM 与 IRP

三个战略层次

企业战略 → 信息系统战略（ISSP）→ IT 战略。

BITA（IT 对齐业务）vs EITA（IT 与业务融合/使能）。

诺兰三阶段（2026 原题）

中级：整体规划、分别实施；

4 步骤；定义企业过程为核心；用 PO（过程/组织）、RD（资源/数据）、CU（创建/使用）矩阵。

CHAPTER 08 · 项目管理（上）
案例 + 选择题双线高频

WBS · 进度网络 · 挣值 · 成本估算

WBS 工作分解

100% 原则：所有工作逐层分解到工作包，不多不少。

谈判口诀："决不让步，除非交换"。

依赖关系两种图

PDM 前导图（单代号，支持 FS/FF/SS/SF 四种）。

ADM 箭线图（双代号，仅 FS，需虚活动表达逻辑）。

关键路径与赶工

关键路径=最长路径，决定工期；总时差为 0。

赶工（加资源换时间）/ 快速跟进（并行改风险）；Brooks 定律：向延期项目加人只会更晚。

挣值分析（必算）
CV = EV−AC　SV = EV−PV
CPI = EV/AC　SPI = EV/PV

EAC / ETC 按典型/非典型偏差分别套公式。

成本估算三法
德尔菲三点 E=(a+4m+b)/6
类比 LOC =（重设计%+重编码%+重测试%）/3 × 已有 LOC

COCOMO：基本 / 中间 / 详细三级。

PERT vs Gantt

PERT 三点估算、展示任务依赖；Gantt 横道图直观展示进度与里程碑，但不显依赖关系。

成本基线 · 配置管理 · 质量与风险

储备与成本基线

管理储备应对"未知的未知"：不计入成本基线、不参与挣值计算；应急储备则计入基线。

三基线：功能基线、分配基线、产品基线。

质量模型与 QA/QC

GB/T 25000.10 八特性：功能性、性能效率、兼容性、易用性、可靠性、安全性、维护性、可移植性。

QA 重在过程预防，QC 重在产品检查；"质量是计划出来的"。

风险管理

组织与责任

CHAPTER 09 · 信息安全（上）
高频！高频！高频！

加密 · 摘要签名 · 证书 · 攻击

对称加密

加解密同钥、速度快。大批量数据加密首选 AES；DES 已不安全；3DES 用两个 56 位密钥、共 112 位。

非对称与数字信封

RSA 密钥 512 位，安全性基于大数分解难题，速度慢，用于签名/密钥交换。

数字信封=随机对称钥加密正文 + 公钥加密对称钥。

摘要与数字签名

MD5 输出 128 位；SHA-1 输出 160 位。

签名三点保证：身份鉴别、不可否认、完整性（私钥签、公钥验）。

PKI 与证书

CA 认证中心 + X.509 数字证书；CRL 证书吊销列表。

KMI（封闭网）/ PKI（开放网，只提供签名服务）/ SPK：LPK 用 RSA、CPK 用 DLP 或 ECC。

攻击辨析

被动攻击：窃听、业务流分析（只看不改）；主动攻击：篡改、伪造、重放、拒绝服务。

防重放：时间戳 / 序列号 / 一次一密。

身份认证强度

口令认证（最不安全）→ 动态口令（一次一密）→ 生物特征识别（指纹/人脸）。

CHAPTER 09 · 信息安全（下）
协议 · 访问控制 · 容灾

SSL/IPSec · 防火墙 · 模型 · 等保容灾

安全协议

SSL/TLS：握手 + 记录 + 报警三协议，端口 443。

IPSec：AH 只认证不加密、ESP 加密+认证；网络层安全。

防火墙与 VPN

结构演进：双宿主机 → 屏蔽主机 → 屏蔽子网（DMZ 非军事区）。

VPN 五大关键技术：隧道、加密、密钥管理、身份认证、访问控制。

访问控制

三要素：主体、客体、控制策略。

DAC 自主 / MAC 强制 / RBAC 基于角色（0～3 级）/ TBAC 基于任务。

BLP vs Biba（必考对比）

BLP 保机密性：不上读、不下写；

Biba 保完整性：不下读、不上写。

等级保护

等保 2.0 分五级：用户自主→系统审计→安全标记→结构化→访问验证，级别越高越严。

容灾与 RPO/RTO

冷备 / 热备 / 双活（双中心）。RPO 能容忍丢多少数据、RTO 能容忍停多久。

2026 案例直播重 RTO、点播重 RPO。

规划步骤 · 立项 · 可行性 · 问题分析

立项管理

可行性分析 4 维

问题分析 4 步（新考点）

上下文图 5 步构建

定系统边界 → 找外部实体 → 识别数据流 → 画 0 层上下文图 → 逐层分解并校验平衡。

系统分析阶段

三难点：问题空间理解、人与人沟通、环境不确定性。

核心产出：SRS 软件需求规格说明书（逻辑模型）。

DFD + 经济效益计算

流程分析 · DFD 原则 · NPV 与回收期

业务流程分析

5 种分析法；工具：TFD 业务流程图、BAM 业务活动图、UML 活动图。

BPM 三层：业务规范层、方法层、产品（平台）层。

DFD 四要素

外部实体、加工（过程）、数据流、数据存储。

DFD 绘制原则（案例命根）

每个加工有入必有出；数据存储与外部实体之间不得直连；父子图须平衡（出入流一致）。

净现值 NPV
NPV = Σ (CI−CO)ₜ / (1+i)ᵗ

NPV > 0 项目可行；折现：P = F/(1+i)ⁿ。

投资回收期
T = 转正年份−1 + |上年累计| / 当年净现金流

投资收益率 = 1 / 回收期（静态口径）。

两个矩阵别混淆

候选方案矩阵用于多方案选型打分；可行性分析矩阵用于按四维度论证单个/多个方案可行性。

CHAPTER 14 · 软件测试
几乎每年必考

黑白盒 · 静动态 · 四级测试

测试的目的

以发现错误和缺陷为目的，而非证明软件无错；尽早测试、贯穿生命周期、可追溯。

软件重用 5 方式

函数重用、对象重用、模块重用、类重用、算法重用（2025 年原题选项辨析）。

黑盒测试

等价类划分、边界值分析、因果图、判定表、错误推测、场景法；不看内部结构。

白盒覆盖（由弱到强）

语句 → 判定（分支）→ 条件 → 判定/条件 → 条件组合 → 路径覆盖（最严格）；工程用 McCabe 基本路径法。

静态 vs 动态

静态测试（评审、走查、静态分析）不运行程序，可发现 30%～70% 缺陷；动态测试需实际运行。

2025 论文静态与动态测试结合。

测试阶段与回归

单元（开发自测）→ 集成（灰盒，自顶向下/底向上/三明治）→ 系统 → 验收（用户主导）。

回归 4 策略 + 冒烟测试；2026 论文考 LLM 生成测试用例。

CHAPTER 15 · 系统运行与维护
2025 爆发年

可用性 · 维护分类 · 遗留系统

运维指标口诀

MTTR 平均修复、MTBF 平均无故障（=MTTF+MTTR）、MTTF 平均故障前时间、MTTA 平均响应。

可用性公式
A = MTBF / (MTBF + MTTR)

2025 案例MTBF=5000h、MTTR=2h → A≈99.96%。

故障管理

故障分类三个维度；故障管理五活动：发现 → 受理 → 处理 → 恢复 → 关闭复盘。

软件维护四分类

改正性（修bug）、适应性（央行调利率改系统，2025 真题）、完善性（最多）、预防性："今天的方法学用于昨天的系统，满足明天的需要"。

维护性度量

维护阶段占生命周期 60% 以上（2025 选择题）；6 子特性：模块化、可重用、易分析/修改/测试、依从性；内部用 McCabe 环路数。

遗留系统四象限

低价值低质量→淘汰；低价值高质量→继承；高价值高质量→改造；高价值低质量→集成。系统转换：直接 / 并行（最常用） / 分段。

CHAPTER 17 · 嵌入式系统
2026 案例：RTOS vs Linux

分层架构 · 实时调度 · 优先级反转

四层架构

硬件层 → HAL/BSP 板级支持包 → 嵌入式操作系统 → 应用层。

实时与内核

硬实时 VxWorks（错过截止期即失败）vs 软实时 Android；宏内核（Linux）vs 微内核（Minix、QNX）。

RMS 速率单调调度

静态优先级，周期越短优先级越高。

Σ Eᵢ/Tᵢ ≤ n(2^(1/n) − 1) ≈ 69.3%

是充分非必要条件，超限未必不可调度。

EDF 最早截止期

动态优先级，CPU 利用率理论上限 100%，但运行期开销大、实现复杂。

优先级反转

优先级继承协议：存在阻塞链；优先级天花板协议：直接抬到天花板，可避免死锁与链式阻塞。

选型与可靠性

RTOS：KB 级体积、毫秒级启动；嵌入式 Linux：生态丰富、适合端侧 AI。容错：TMR 三模冗余 vs 监控-启动器（双机）。

CHAPTER 19 · 大数据处理
Lambda / Kappa 必考对比

4V 特征 · 两类架构 · 生态工具

4V 特征

数据量大 Volume、类型多 Variety、速度快 Velocity、价值密度低 Value。

大数据处理 6 原则

伸缩性、可靠性、容错、低延迟、可扩展、成本效率（围绕集群与数据本地性）。

Lambda 架构

批处理层（全量、精确）+ 加速层（实时流）+ 服务层合并查询。

缺点：两套代码、维护成本高。

Kappa 架构

纯流式架构，用 Kafka/Pulsar 日志重放代替批处理层重算历史，一套代码。

易错点辨析

流处理保实时性、批处理保最终一致性/精确；需要频繁历史数据重算时 Lambda 更占优。

IOTA 与生态

IOTA：边缘采集、去 ETL；采集同步 Sqoop/DataX；流计算 Flink Watermark 处理乱序；图计算 GraphX。

CHAPTER 20 · 微服务架构（上）
近年最热 · 案例常客

拆分原则 · DDD · 通信与治理

微服务 vs 单体

优点：独立部署、技术异构、故障隔离、按需伸缩；缺点：分布式复杂度、运维成本高。不是所有系统都适合。

拆分原则

单一职责、服务自治、按业务能力拆分；用 DDD 限界上下文划边界，避免过度拆分（100+ 服务反模式）。

原则辨析题

去中心化治理与数据管理才是微服务特征；"集中式治理"不属于微服务原则（2025 考点）。

同步 vs 异步

同步 RESTful/gRPC：强实时，如下单调用支付；异步 Kafka：解耦削峰。全链路同步有雪崩级联风险。

案例三主线

怎么拆（边界）→ 数据怎么一致（分布式事务）→ 拆完怎么管（治理）。

Service Mesh

服务网格：控制面 + 数据面 Sidecar，把熔断/限流/追踪从业务代码下沉到基础设施层。

CHAPTER 20 · 微服务架构（下）
分布式事务 · 容错 · 安全

BASE · 可靠消息 · 断路器 · 容器化

2PC 的边界

两阶段提交强一致，但同步阻塞、协调者单点、可能死锁，不适合互联网高并发场景。

BASE 理论

基本可用、软状态、最终一致性；用短时间的不一致换取高可用与吞吐。

分布式事务三件套

可靠消息（本地消息表 + MQ）、TCC（Try-Confirm-Cancel）、Saga（长事务+补偿）。

资金场景选型

强一致资金链路可用 Seata AT；异步场景用 RocketMQ 事务消息保障本地操作与发消息原子性。

容错与注册中心

容错四机制 + 断路器（Hystrix / Sentinel）防雪崩；注册中心：Consul、ZooKeeper(ZAB)、Eureka、Etcd(Raft)。

交付与安全

Docker 容器 + Kubernetes 编排 + Jenkins 流水线；OAuth2 四授权模式；JWT 三段式（Header.Payload.Signature）无状态令牌。
