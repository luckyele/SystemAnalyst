# 信息化战略与规划复习笔记（ASD-STE100 风格）

## 0. 本笔记的写作规则

本笔记遵循 ASD-STE100 规范的核心规则。规则如下：

1. 每个句子只讲一个主题。
2. 描述句不超过 25 个词。步骤句不超过 20 个词。
3. 使用主动语态。使用现在时。
4. 使用确定的词。不使用"可能"、"大概"、"有些"这类模糊词。
5. 步骤使用编号。步骤使用祈使句。

> 说明：ASD-STE100 是为英语技术文档制定的规范。本笔记把它的规则应用到中文写作中。

## 1. 基本概念

- 信息化战略与规划属于企业信息化模块。该模块占综合知识约 3% 至 5%。
- 本主题包含三个考点：诺兰模型、BPR、ISSP。
- 诺兰模型判断企业信息化所处阶段。
- BPR 改造企业的业务流程。
- ISSP 规划信息系统的建设方向。

## 2. 诺兰模型

### 2.1 定义与用途

- 诺兰模型由诺兰提出。
- 该模型描述企业信息化的发展阶段。
- 模型共有 6 个阶段。
- 考试考点：阶段排序、阶段特征判断。

### 2.2 六个阶段

| 序号 | 阶段 | 核心特征 |
|---|---|---|
| 1 | 初装 | 组织购置第一台计算机。应用初步开展。 |
| 2 | 蔓延 | 应用快速扩张。缺乏统一管理。数据冗余严重。 |
| 3 | 控制 | 成立领导小组。统一规划。控制预算。 |
| 4 | 集成 | 统一数据库。统一信息系统。重新设计应用。 |
| 5 | 数据管理 | 数据成为组织重要资源。日常处理由系统完成。 |
| 6 | 成熟 | 信息系统支持组织战略。信息资源管理达到高水平。 |

### 2.3 两个时代

- 前 3 个阶段属于"计算机时代"。特点是数据分散。
- 后 3 个阶段属于"信息时代"。特点是数据集中。
- 转折点在第 3 阶段与第 4 阶段之间。
- 考题给出特征描述。考生判断所属阶段。

## 3. BPR 业务流程再造

### 3.1 定义

- BPR 由哈默与钱皮提出。
- BPR 对业务流程做根本性再思考。
- BPR 对业务流程做彻底性再设计。
- 目标是在成本、质量、服务、速度上取得显著改善。

### 3.2 四个核心特征

| 特征 | 含义 |
|---|---|
| 根本性 | 重新思考流程存在的前提。 |
| 彻底性 | 重新设计流程。不做小修补。 |
| 显著性 | 绩效取得大幅改善。不是小幅提升。 |
| 流程导向 | 改造对象是流程。不是部门。 |

### 3.3 BPR 与 BPM 的对比

| 对比项 | BPR | BPM |
|---|---|---|
| 变革方式 | 一次性彻底变革 | 持续渐进优化 |
| 变革幅度 | 大 | 小 |
| 出发点 | 流程重构 | 流程全生命周期管理 |

- 题干出现"持续优化流程"。答案选 BPM，不选 BPR。

### 3.4 实施步骤

按以下顺序实施 BPR。

1. 识别核心业务流程。
2. 分析现有流程的问题。
3. 重新设计流程。
4. 实施新流程。
5. 评估实施效果。

### 3.5 论文关联

- BPR 是论文高频主题。
- 论文结构：流程诊断 → 再设计方案 → 信息化支撑 → 效果评估。

## 4. ISSP 信息系统战略规划

### 4.1 定义与定位

- ISSP 的全称是 Information System Strategic Planning。
- 中文为信息系统战略规划。也称信息化战略规划。
- ISSP 承接企业战略。ISSP 指导信息系统建设。
- 规划层次共 3 层。顺序为：企业战略 → 信息化战略（ISSP）→ 信息系统规划。
- 考点：ISSP 必须与企业战略保持一致。

### 4.2 三大经典方法

| 方法 | 全称 | 核心思想 | 关键工具 |
|---|---|---|---|
| BSP | 企业系统规划法 | 自上而下识别企业目标。自下而上设计系统。 | U/C 矩阵 |
| CSF | 关键成功因素法 | 识别影响目标的关键因素。聚焦少数重点。 | 关键成功因素分析 |
| SST | 战略集合转移法 | 把组织战略集合转换成信息系统战略集合。 | 战略集合映射 |

### 4.3 方法选用要点

- BSP 最常用。考试出现"自上而下、自下而上"即指 BSP。
- CSF 适合高层决策场景。关注点少而关键。
- SST 强调战略的映射转换。
- U/C 矩阵用于划分子系统。矩阵需检验一致性。

## 6. 关键词速查

| 题干关键词 | 答案 |
|---|---|
| 第一台计算机 | 诺兰模型：初装阶段 |
| 扩张快、无统一管理、数据冗余 | 诺兰模型：蔓延阶段 |
| 领导小组、统一预算 | 诺兰模型：控制阶段 |
| 统一数据库、重新设计应用 | 诺兰模型：集成阶段 |
| 数据成为重要资源 | 诺兰模型：数据管理阶段 |
| 信息系统支持组织战略 | 诺兰模型：成熟阶段 |
| 根本性、彻底性、显著改善 | BPR |
| 持续、渐进、优化 | BPM |
| 自上而下、自下而上、U/C 矩阵 | BSP |
| 关键因素、高层关注 | CSF |
| 战略集合、转换 | SST |

## 7. 易混淆对比

| 对比项 | 区分标准 |
|---|---|
| BPR vs BPM | BPR 看彻底变革。BPM 看持续优化。 |
| 控制阶段 vs 集成阶段 | 控制阶段管预算和规划。集成阶段统一数据库和应用。 |
| 蔓延阶段 vs 控制阶段 | 蔓延阶段无管理。控制阶段开始管理。 |
| BSP vs CSF | BSP 走全覆盖路线。CSF 走重点突破路线。 |
| ISSP vs 信息系统规划 | ISSP 定战略方向。信息系统规划定实施方案。 |

## 8. 考点与分值

- 综合知识考 1 至 2 分。形式为单选题。
- 高频考题为诺兰模型阶段判断。
- BPR 考定义和四特征。
- ISSP 考三大方法的区分。
- 论文方向：BPR 业务流程再造（见整体概况第 180 行）。

## 9. 自测题

做题时不要看答案。做完后再核对。

**题 1**：某企业各部门大量购置计算机。应用无统一计划。数据冗余严重。该企业处于哪个阶段？

答：蔓延阶段。

**题 2**：某企业成立信息化领导小组。统一编制预算。加强数据管理。该企业处于哪个阶段？

答：控制阶段。

**题 3**：某企业对订单流程做根本性再思考。做彻底性再设计。成本下降 40%。这体现了哪个方法的特征？

答：BPR。对应根本性、彻底性、显著性三特征。

**题 4**：某企业采用"自上而下识别目标、自下而上设计系统"的方法。该企业使用了哪种方法？

答：BSP 企业系统规划法。

**题 5**：某企业先列出影响目标的少数关键因素。再针对这些因素做规划。该企业使用了哪种方法？

答：CSF 关键成功因素法。

**题 6**：某企业每季度对流程做小幅优化。不推翻现有流程。该企业的做法属于哪种方法？

答：BPM。持续渐进优化不属于 BPR。
