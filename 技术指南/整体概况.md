系统分析师考试整体知识体系分为**基础知识、关键技术、案例实践三大板块**，下设约 18 个知识模块，覆盖综合知识、案例分析与论文三科考点。

## 一、框架总览

| 篇章       | 模块定位                                 | 综合知识分值占比  | 主要考查形式          |
| -------- | ------------------------------------ | --------- | --------------- |
| 第一篇 基础知识 | 数学、计算机系统、网络、数据库、企业信息化、软件工程、项目管理、信息安全 | 约 55%–65% | 选择题为主           |
| 第二篇 关键技术 | 系统规划与分析、需求工程、架构设计、系统设计、实现与测试、运行与维护   | 约 25%–35% | 选择题 + 案例分析 + 论文 |
| 第三篇 案例实践 | Web、嵌入式、移动、大数据、微服务、信息物理系统等场景化分析      | 融入案例与论文   | 案例分析 + 论文       |

## 二、第一篇 基础知识模块

### 模块 1　数学与工程基础（约 3%–5%）

- 概率统计：古典概率、随机变量与分布、数字特征、常用分布、统计分析方法
- 图论应用：最小生成树、最短路径、网络与最大流量
- 预测与决策：预测方法、决策树、乐观/悲观/折衷准则
- 数学建模：建模方法、分类与流程
- 工程伦理：技术伦理、工程师职业伦理

### 模块 2　计算机系统（约 9%–17%）

- 计算机体系结构：层次结构、硬件组成、RISC/CISC、SMP/MPP/集群
- 存储器系统：主存、Cache、虚存、网络存储（NAS/SAN）、RAID
- 输入输出系统：I/O 方式、总线、接口
- 可靠性计算：串联/并联/冗余、MTBF/MTTR、阿姆达尔定律
- 操作系统：进程/线程、PV 操作、死锁四条件与银行家算法、分页/分段、页面置换（OPT/FIFO/LRU）、磁盘调度（FCFS/SSTF/SCAN）、微内核、国产操作系统

### 模块 3　计算机网络与分布式系统（约 7%–9%）

- 数据通信基础：编码、调制、差错控制（CRC、海明码）
- 体系结构与协议：OSI 七层、TCP/IP 四层、TCP 三次握手/四次挥手、UDP
- 局域网与广域网：以太网、WLAN、广域网技术
- 网络工程：规划、设计、实施
- 分布式系统：透明性、中间件分类（RPC、消息、对象中间件）
- Web 服务与云计算：SOAP/WSDL/UDDI、RESTful、IaaS/PaaS/SaaS

### 模块 4　数据库系统（约 9%–16%）

- 数据库管理体系：三级模式两级映像、数据独立性
- 关系数据库：关系代数、SQL、函数依赖、范式 1NF–4NF、键与依赖
- 数据库控制：事务 ACID、隔离级别、并发异常（丢失修改、不可重复读、脏读、幻读）、两段锁协议
- 数据库设计与建模：ER 图、ER 转关系模式
- 分布式数据库、数据仓库与 OLAP、数据挖掘
- 非关系数据库：KV、文档、列族、图数据库

### 模块 5　企业信息化（约 3%–5%）

- 信息与信息系统基本概念、系统工程方法论
- 信息化战略与规划：诺兰模型、BPR、ISSP
- 企业资源规划：ERP、CRM、SCM、DSS
- 系统集成：数据集成、应用集成、表示层集成

### 模块 6　软件工程（约 10%–15%，分值最高）

- 开发模型：瀑布、增量、迭代、螺旋、原型、敏捷（Scrum、XP）
- 需求工程：功能/非功能需求、需求获取-分析-验证-管理
- 面向对象方法：UML 全套图（用例图、类图、时序图、通信图、状态图、活动图、构件图、部署图）、include/extend、聚合/组合
- 设计原则与模式：SOLID 七大原则、GoF 23 种设计模式
- 软件质量模型：ISO/IEC 9126 六大特性
- CMMI 成熟度五级

### 模块 7　项目管理（约 8%–12%）

- 十大管理领域（范围、进度、成本、质量、风险等）
- 进度管理：关键路径 CPM、甘特图、总时差与自由时差
- 质量工具：PDCA、鱼骨图、帕累托图、控制图
- 成本估算：类比估算、专家判断、三点估算、挣值分析
- 风险管理：风险识别、定性/定量分析、应对策略

### 模块 8　信息安全（约 5%–8%）

- 安全属性：CIA 三元组
- 加密体系：对称/非对称加密、MD5/SHA 摘要、数字签名、X.509 数字证书
- 攻击与防御：SQL 注入、XSS、CSRF、DDoS；防火墙、IDS/IPS、WAF
- 访问控制：DAC、MAC、RBAC
- 等级保护 2.0、安全体系架构

## 三、第二篇 关键技术模块

### 模块 9　系统规划与分析（约 8%–12%）

- 系统规划：可行性研究（技术、经济、操作可行性）
- 系统分析：组织结构分析、业务流程分析、数据流图 DFD（父图/子图平衡）
- 系统建模：DFD 分层细化、数据字典、加工逻辑说明
- 系统建模方法：结构化方法与面向对象方法的对比

### 模块 10　软件需求工程（约 6%–10%）

- 需求获取：访谈、问卷、观察、原型、用户故事地图、实例化需求
- 需求分析：DFD、ER、用例模型、面向对象分析
- 需求规格说明书 SRS 结构
- 需求验证：评审、需求可追溯性矩阵、决策表
- 需求管理：变更控制、基线管理、需求跟踪

### 模块 11　软件架构设计（约 8%–12%）

- 架构风格：分层、管道过滤器、仓库、事件驱动、C/S、B/S、SOA、微服务、云原生
- 架构评估：质量属性场景（性能、可用性、安全性、可修改性、可测试性）、ATAM、SAAM
- 中间件与构件：CORBA、EJB、COM、WebService
- 分布式架构：负载均衡、集群、高可用、容错设计
- TOGAF 10.0 与 ADM 架构开发方法

### 模块 12　系统设计（约 6%–10%）

- 概要设计：模块划分、内聚与耦合、模块独立性
- 详细设计：程序流程图、N-S 图、PAD 图、伪代码
- 界面设计、数据设计
- 面向对象设计：设计模式应用、类职责分配
- 数据库详细设计：索引、分库分表、读写分离

### 模块 13　软件实现与测试（约 5%–8%）

- 程序编码规范、编程语言选择
- 软件测试：V 模型、W 模型、H 模型；黑盒/白盒测试；单元/集成/系统/确认/验收测试
- 测试用例设计：等价类、边界值、因果图、判定表、正交试验
- 面向对象测试、性能测试、压力测试
- 调试与缺陷管理

### 模块 14　系统运行与维护（约 4%–7%）

- 系统部署与上线、系统转换策略（直接、并行、分段、试点）
- 运维管理：ITIL、ITSS、运维体系
- 系统维护类型：改正性、适应性、完善性、预防性维护
- 系统评价：性能监控、可靠性分析、可用性度量

## 四、第三篇 案例实践模块

### 模块 15　典型信息系统分析与设计

覆盖新大纲明确列出的六大场景化方向：

- Web 应用系统分析与设计
- 嵌入式系统分析与设计
- 移动应用系统分析与设计
- 大数据处理系统分析与设计（Lambda 架构、Spark、Flink）
- 微服务系统分析与设计（DDD、服务拆分、治理）
- 信息物理系统 CPS（数字孪生、物理-信息融合）

### 模块 16　标准化与知识产权（约 3%–5%）

- 软件著作权：自动取得、署名权永久、财产权保护期
- 专利、商标、商业秘密
- 开源协议：GPL、Apache、MIT、BSD 的差异
- 标准化：国际标准/国家标准/行业标准/企业标准、强制性/推荐性标准

### 模块 17　经济、管理与专业英语（约 8%–10%）

- 会计与财务基础：报表、成本分析、投资回收期、净现值 NPV
- 运筹学：线性规划、排队论、博弈论基础
- 专业英语：软件工程、架构、新技术英文短文阅读（固定 5 分）

### 模块 18　新技术与应用（综合知识 + 案例重点）

- 云计算与云原生：Docker、Kubernetes、服务网格
- 大数据：Hadoop 生态、数据治理、数据中台
- 人工智能与机器学习：典型应用场景、AI 赋能系统设计
- 区块链、边缘计算、5G、物联网
- 数字化转型：成熟度模型、实施路径、企业数字化战略

## 五、三科考查侧重与备考要点

**综合知识**：75 道单选、150 分钟，覆盖上述 18 个模块，重点在计算机系统、数据库、软件工程、架构设计四大块，合计约 40% 分值；运筹计算、知识产权、专业英语为稳定拿分项。
**案例分析**：必答 1 题 + 四选二共 3 题、90 分钟，固定围绕四大方向轮换出题：

| 案例方向                                                                                                                                                                       | 核心考点                        |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| 数据流图 DFD                                                                                                                                                                   | 补缺失数据流、父图子图平衡、加工逻辑说明        |
| 数据库设计                                                                                                                                                                      | ER 图补全、范式判断、SQL 改错、事务与并发    |
| UML 面向对象                                                                                                                                                                   | 用例图改错、类图补类、时序图补消息           |
| 系统架构设计                                                                                                                                                                     | 架构风格选型、质量属性权衡、ATAM 评估、可靠性计算 |
| **论文写作**：四选一、120 分钟、2200–2700 字，结构为"摘要 300 字 + 正文（项目背景 → 需求 → 方案 → 实践 → 问题解决 → 总结）"。高频主题包括：需求分析方法、软件架构设计、面向对象分析设计、数据库设计与优化、性能优化与高可用、系统安全设计、BPR 业务流程再造、数据仓库与数据挖掘、微服务与云原生架构。 | <br />                      |

***

## 六、备考优先级建议

1. **最高优先级（三科联动）**：数据库（ER、范式、事务、锁）、UML 与设计模式、DFD 数据流图、架构风格与质量属性、操作系统经典算法
2. **次优先级**：计算机网络、信息安全、项目管理、运筹计算、知识产权
3. **稳定拿分项**：专业英语 5 分、标准化与知识产权、经济管理常识
4. **论文素材库**：建议提前准备 2–3 篇不同主题的论文框架（如微服务架构、需求管理、性能优化），结合真实项目经验反复打磨
