7公式与易错点

虚页号 = ⌊虚拟地址 ÷ 页大小⌋
页内偏移 = 虚拟地址 mod 页大小
实地址 = 实页号 × 页大小 + 页内偏移
偏移位数 = log₂(页大小) = 10
虚页号位数 = log₂(页面数) = 3
偏移 ≠ 实地址：1023 只是页内偏移，实地址要再乘加实页号，得 4095。
1023 属于第 0 页：地址从 0 编号，第 0 页覆盖 [0,1023]，偏移取满值。
装入位为 0 即缺页：本题失效虚页号为 2、3、5、7，不产生实地址。
越界自检：实地址应小于主存容量，4095 < 4096 ✓。
