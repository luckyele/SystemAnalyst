## 1.2 六大病根（跨题错因穿透）

所有 63 题的失分，穿透到认知层只有六个病根。**每道错题都能归入其中一类，复习就是按病根修，而不是按题刷。**

### 病根① "特征↔类别名"配对记忆不牢（重灾区，约 22 题）

> 涉及：02, 07, 20, 22, 23, 25, 32, 38, 39, 40, 44, 47, 48, 49, 52, 53, 55, 57, 58, 59, 60, 63

教材中的**封闭清单**（三层透明性、构件接口三类、内聚七级、耦合排序、CMM 五级、区块链六层、测试四阶段、安全四分类、架构五大类、智能四特征、IE 四阶段）只记了大框架，没把"关键词锚点"绑死在类别名上。出题人专门制造两类杀伤：
- **编造项**：命名不兼容（22）、物理/全局透明性（23/25）、共享内存当风格名（59）、鱼刺图顶替判定表（57）——凡清单里没有的名字，就是"不包括/不属于"题的答案；
- **近似漂移**：已定义冒领已管理的"量化"特征（55）、确认测试顶替集成测试（52）。

**处方**：每套清单背一张"关键词→类别"速查表（见第三部分通式三），不背名字背指纹。

### 病根② 成对相近概念缺"唯一判据"（约 18 题）

> 涉及：08, 09, 10, 12, 16, 17, 29, 30, 33, 35, 37, 38, 43, 46, 47, 50, 54, 56

两个概念共享 90% 特征、只差一条判据，而记忆停留在"名字印象"层。每对概念必须绑定一句**判别问句**：

| 概念对 | 唯一判据（判别问句） |
| --- | --- |
| 主键/候选键 vs 外键 | 它**唯一标识本关系**，还是**指向别人关系的主键**？（08） |
| 完整性 vs 安全性 vs 可靠性 | 数据**对不对**（完整）/ 人**能不能看**（安全）/ 坏了**还能不能跑**（可靠）（09） |
| 自然连接 vs 等值连接 vs 笛卡尔积 | 同名属性**合并了吗**？合并→自然连接（m+n−k 列）；保留两份→等值连接（m+n 列）（10） |
| 部分依赖 vs 传递依赖 | 非主属性依赖**键的一部分**（卡 2NF）还是依赖**另一个非主属性**（卡 3NF）？（12/14） |
| 可用性 vs 一致性（CAP） | 有**响应**即可用——旧数据也算可用（16） |
| 缓存 vs 分布式文件系统 | 数据**可丢可回源**=缓存；**不可丢**=文件系统（17） |
| 图中心 vs 图重心 | 优化**最坏情况**（min-max）还是**总效率**（min-sum）？（29） |
| 泛化 vs 聚合 | **is-a**（分类）还是 **is-part-of**（组成）？（30） |
| CPS vs 物联网 | **闭环控制**（CPS=3C 核心 Control）还是开环感知互联？（33） |
| 过程内聚 vs 顺序内聚 | 靠**控制流次序**驱动还是**数据流**（前一步输出=后一步输入）驱动？（35/38） |
| 组合 vs 聚合 | 部分**能否脱离整体独立存在**？（37） |
| 原型 vs 螺旋 | 题干重心是**需求不明**还是**风险大**？（43） |
| 3NF vs BCNF | 左部是**超键**（含候选键即可）就行，不必恰等于候选键（46） |
| DSS vs IDSS | 知识库+推理机是 **IDSS 的增量**，不在 DSS 两库结构内（47） |
| 用例模型 vs 分析模型 | 用例图配**需求**阶段，类图配**分析**阶段（50） |
| 对称 vs 非对称 | 对称**快**、管大数据量；非对称**慢**、管密钥分发签名（54） |
| 继承 vs 改造（遗留系统） | 改造的前提是**技术含量高**；技术低价值高只能继承（56） |

**处方**：做题先套判别问句，再对号入座——不是"感觉像谁"。

### 病根③ 公式记形不记质 + 前置口径折算缺失（约 12 题）

> 涉及：03, 05, 06, 19, 26, 27, 28, 51, 61, 62（+ 05/27/51 同一坑反复踩）

两类失效模式：
- **形近公式互换**：并联可靠性误用 1−R³（那算的是"全失效"，正确是 1−(1−R)³）（06）；单缓冲误用 max(R,S+P)（03）；
- **代入前不做口径折算**：页面大小不先写成 2 的幂就切位宽（51，与 27 重复踩坑）；RAID 忘"混合容量取最小盘"（19）；盈亏平衡不把可变成本总额折成比率、漏扣税率（62）；贝叶斯只比似然不乘先验（61）。

**处方**：所有计算题执行三步军规——**①定口径（2 的幂/最小盘/折算比率/先验×似然）→ ②套通式 → ③回代验算**（如"实地址 < 主存容量""结果为最小容量整数倍"）。详见第三部分通式一。

### 病根④ 字面诱导 / 主宾混淆 / 反向设问（约 12 题，纯审题失分）

> 涉及：04, 08, 21, 22, 25, 33, 41, 43, 45, 49, 52, 59, 63

- **字面匹配陷阱**：变量名 available/data 与教材 empty/full 不一致就卡壳（04）；"信息资源规划"看到"信息资源"就选主线（49，同义反复）；"与客户相关"联想原型而题干重心是风险（43）；"接入层流量"看到"接入层"就选，没看清动作主体是**汇聚**层（41）；
- **反向设问**："不正确/不属于/不包括"看反，把真实存在项当答案（21/22/25/33）；
- **半对选项**：双空题只对一半没警惕（52）；被眼熟的选项"第一眼就选"（63 选了第二步当第三步）。

**处方**：审题三步军规——**①圈反向词（不/非/除/最高/最低/第三步）→ ②找动作主体（谁做什么，而非词面像什么）→ ③选完回读设问方向**。

### 病根⑤ 多因子决策退化成单因子直觉（约 7 题）

> 涉及：14, 16, 42, 46, 56, 61, 62

题目给两个以上因子，凭最显眼的一个下结论：遗留系统只看"价值高"不看"技术低"（56）；贝叶斯只比次品率不乘产量先验（61）；死锁题把"排除互斥"读成"保留互斥"，没注意题干恰恰锁死互斥不可破坏（42）；范式判定不逐级检查、跳级结论（14/46）。

**处方**：多因子题必须**逐维提取取值再综合**——二维题列四象限表，概率题写"后验 ∝ 先验 × 似然"，范式题走逐级台阶"卡级即停"。

### 病根⑥ 流程/序列题"记元素不记顺序"（约 6 题）

> 涉及：23, 31, 36, 40, 45, 55, 63

OOA 四步、OOD 三步、IE 四阶段、CMM 五级、TCP 状态机、区块链六层、透明性三层——组成项背得出，**顺序与序号**对不上：63 题把第二步"构造交互图"当第三步；55 题"三级定、四级量"错位；36 题 SYN_SENT/SYN_RCVD 主体相反。

**处方**：序列必须配口诀 + 明确"谁在第几位"（口诀库见第三部分通式二附表）。

**错题穿透表**

| 题 | 表面错因 | 深层病根 |
| --- | --- | --- |
| 03 单/双缓冲 | 单缓冲误用 max 公式；丢首末块 | 病根③：公式记形不记质（单缓冲=串行占用 R+S） |
| 04 PV 操作 | 变量名不同就选不出 | 病根④：字面依赖，没做语义映射（available≡empty, data≡full） |
| 05 页表映像 | 偏移/实地址/实页号三个数混淆 | 病根③：多步计算细节丢失，缺回代验算 |

| 51⚑ 页号速算 | 把"4"（KB）当位宽，没转 2 的幂 | 病根③：**同一坑第三次踩**，最高优先级 |
| 42 死锁条件 | 把"排除互斥"读反 | 病根⑤：题干锁定互斥不可破坏 |

**一类题通式**

1. **缓冲区类**（03）：标出 R（读入）/S（传送）/P（处理）→ 定瓶颈周期：单缓冲 R+S、双缓冲 max(R,S+P) → 套 **T = 首块完整耗时 + (n−1)×瓶颈周期 + 尾部耗时**。
2. **PV 操作类**（04）：按初值认语义（初值 N=资源空位 empty、初值 0=数据 full、初值 1=互斥 mutex）→ 铁律：**同步 P 在互斥 P 前**（否则死锁）、mutex 成对紧包临界区 → 自检 empty+full=N 恒成立。**变量名永远换成语义再做**。
3. **分页地址类**（05/27/51，三题一个通式）：① 页面大小写成 **2^k** → 偏移占低 k 位（十六进制 k/4 位）；② 逻辑地址**从右砍 k/4 位十六进制**，余下高位=页号；③ 实地址=实页号×页大小+偏移；④ **回代验算**：页号×页大小+偏移=原地址、实地址<主存容量。附：装入位=0 即缺页；第 0 页覆盖 [0, 页大小−1]。
4. **死锁类**（42）：默写四条件（互斥/请求保持/不可剥夺/循环等待）→ **互斥天生不可破坏** → 题干语境锁定哪条必须保留 → 答案在其余三条中选可破坏项（一次性申请破持保、允许抢占破不可剥夺、有序分配破循环等待）。

**一类题通式**

1. **CISC/RISC 辨析**（02）：五维口诀——**CISC 多、变、微程序、周期长；RISC 少、定、硬布线、流水线**。信号词：微程序→CISC；只有 Load/Store 访存→RISC。注意定长（编码）≠单周期（执行）。
2. **串并联可靠性**（06）：识结构（先内后外）→ 并联子块 **1−(1−R)ⁿ** → 串联**相乘**。口诀"串联相乘越串越差，并联取反乘越并越好"。锚点：R=0.9 时 2 并联=0.99、3 并联=0.999。
3. **性能评价匹配**（20）：关键词指纹表——"计算单元/字长/求和"→CTP；"指令比例/加权/吉普森"→等效指令速度；"MIPS/MFLOPS"→指令速度法；"实际运行/SPEC/TPC"→基准程序法（最真实可靠）。
4. **流水线阶段**（21）：口诀"取译执访回"；唯一对外写=访存阶段的 Store；回写只写 **CPU 内部通用寄存器**。加速比上限=级数。
5. **浮点表示范围**（28）：三步——拆位宽（总位数−1 符号位）→套区间（**移码阶码 [−2^p, 2^p−1]，补码尾数 [−1, 1−2⁻ⁿ]**）→极值合成（最大正=尾数 max×阶码 max；最小负=−1×阶码 max）。口诀"补码负界 −1，移码上限 2^p−1；负数极值取最大阶码"。

> **📖 章节关键考点（原文摘编）**

> - 信道容量双公式：奈奎斯特 **B=2W**（无噪声）；香农 **C=W·log₂(1+S/N)**；dB 必须先换算成 S/N 再代入——2024 真题 20Mbps 即此套路
> - OSI 与 TCP/IP 分层对应关系；判层看封装：装 IP 包=网络层（**ICMP/ARP 无端口，是"IP 的助手"**）、有独立端口=应用层——【34/39】依据

> - 攻击分类：**业务流分析属被动攻击**（不篡改数据流）；系统安全四分类：实体/运行（**含审计跟踪**）/信息/人员——【58】依据；BLP 上读下写（保机密）、Biba 下读上写（保完整）；RPO/RTO 容灾指标

**一类题通式**

1. **协议判层通式**（34/39 一法通吃）：**看封装**——装帧里→链路层（L2TP/PPTP/802.1X）；装 IP 包→网络层（IPSec/ICMP/ARP/IGMP）；装 TCP/UDP 段→传输层（SSL/TLS）；装应用报文→应用层（HTTPS/SSH/PGP/SET/Kerberos）。信号：协议名带 IP=网络层；有独立端口（443/22）=应用层；ICMP 无端口，是"IP 的助手"（协议号 1）。
2. **TCP 状态机**（36）：先定角色再走路径——主动建连 CLOSED→SYN_SENT→ESTABLISHED；被动建连 CLOSED→LISTEN→SYN_RCVD→ESTABLISHED。锚点：**RCVD=收到了对方 SYN**；CLOSE_WAIT/LAST_ACK/TIME_WAIT 全属挥手；谁先发 FIN 谁进 TIME_WAIT。
3. **园区三层**（41）：口诀"接入管接入选端口（MAC 过滤/VLAN/802.1X/PoE）、汇聚加策略（ACL/路由聚合）、核心快稳简通出口"。**看动作主体，不看宾语里的层名**。
4. **加密体系**（54⚑）：七维对照——对称=同钥+**快**+大数据量（DES/3DES/AES/SM4）；非对称=异钥+慢+易分发+可签名（RSA/ECC/SM2）；摘要=完整性（MD5/SHA/SM3，两边都不是）。口诀"非对称管钥匙，对称管数据，摘要管完整"；n 方通信密钥数：对称 n(n−1)/2，非对称 2n。
5. **安全四分类**（58⚑）：口诀"**物理防砸门、运行防内乱、数据防泄密、管理防人祸**"。审计跟踪（日志）=运行安全标志性内容；环境/设备=物理；加密=数据；制度/意识=管理。

**一类题通式（本板块最重要的流水线）**

**范式判定流水线**（11→12→13→14→46，五题一法）：

```
第1步 属性分类定"必含"：L类(只在左部)必在 / R类(只在右部)必不在 / N类不在F中出现必在 / LR类待验证
第2步 穷举候选键：必含核心 + LR类枚举加入，逐个求闭包 X⁺
      闭包=U 且无真子集满足 → 候选键（可能多个，必须穷举到底！）
第3步 数主属性：主属性 = 所有候选键的并集（可以=全属性，即非主属性为 0 个）
第4步 逐级判定，卡级即停：
      2NF 红线 = 非主属性部分依赖（依赖键的真子集）
      3NF 红线 = 非主属性传递依赖
      BCNF 红线 = 每个非平凡依赖的左部都是超键（含候选键即可，左部有冗余属性不违规）
```

配套铁律：**右部可拆、左部不可拆**（X→YZ ⟹ X→Y，但 XY→Z 推不出 X→Z）；传递律要先验证"链接得上"（A1→A2A3 与 A2A5→A4 之间没有 A1→A5，A1→A4 推不出）。经典反例：STJ（T→J 左部非超键，3NF 但非 BCNF）。

**其他通式**

- **自然连接**（10）：列数=m+n−k（k=同名属性数），元组数=同名属性**全等**的配对数（部分相等不算）；σ 下标是列序号不是数值。
- **约束机制选择**（15）：见"**无共同列+跨表联动**"→触发器；有公共列的参照→外键；本表列规则→check。声明式约束表"规则"，触发器承载"动作"。
- **CAP 三步定位**（16）：题干有网络故障→P 已发生（必选项）；仍响应→A 满足；读到旧数据→C 牺牲 → AP。口诀"P 必选，真取舍在 C/A"。CP=ZooKeeper，AP=Cassandra（BASE 思想）。
- **分布透明性**（23/25）：封闭三层"**分片最高、位置居中、逻辑（局部数据模型）最低**"——"不必知道什么"越多层次越高。编造词黑名单：物理透明性、全局透明性。
- **主从复制**（24）：口诀"**主库 Dump 发，从库 IO 收、SQL 干**"。链路：binlog→Dump 发送→IO 线程收写 relay log→SQL 线程读取执行。

**一类题通式**

1. **开发模型选型**（43）：抓主要矛盾——需求模糊→**原型**；需求稳定→瀑布；分批交付→增量；**高风险→螺旋**（每轮必做风险分析）。螺旋=瀑布+原型+风险分析，四象限：计划→风险分析→工程→客户评估。
2. **UML 关系三连**（30/37）：
   - 语义对：use-a=依赖、has-a=关联、**is-a=泛化、is-part-of=聚合**；
   - 耦合强→弱：**继（承）→组（合）→聚（合）→关（联）→依赖**，口诀"继组聚关（依赖垫底）"；
   - 判据：部分**同生共死=组合**（实心菱形），**可分离=聚合**（空心菱形），仅持有引用=关联。
3. **多态四分类**（35）：关键词映射——类型作参数（模板/泛型）=**参数多态**；子类归父类=**包含多态**；同名多义（重载）=**过载多态**；隐式类型转换=**隐含多态**。**"编译程序判定算子意义"是动作（算子鉴别），不是多态类型**——看清问的是类型还是动作。
4. **内聚七级**（38）：弱→强"**偶逻时过通顺功**"。两维判别：有次序无数据流=过程；输出即输入=顺序；同时段无次序=时间。
5. **CMM 五级**（55⚑）：记忆链"**乱→能重复→有标准→能量化→能改进**"；口诀"**三级定、四级量**"——见"度量/统计/量化"直接锁四级。注意 CMMI 二级叫"已管理级"（与 CMM 名称不同，防串台）。
6. **架构风格速判**（59⚑/60）：两问自检——**连接件定大类**（数据流/调用返回/独立构件/虚拟机/仓库五大类，别漏虚拟机），**控制权定风格**：

| 关键词指纹 | 风格 | 大类 |
| --- | --- | --- |
| 共享数据区、谁懂谁上、知识源 | **黑板** | 仓库 |
| 数据流式处理、增量计算 | **管道-过滤器** | 数据流 |
| 发布-订阅、不知谁响应 | 事件驱动 | 隐式调用（独立构件） |
| 点对点消息、知道对方 | 进程通信 | 独立构件 |
| 相邻层调用、逐层抽象 | 层次结构 | 调用/返回 |
| 方法调用封装 | 面向对象 | 调用/返回（不是独立构件！） |
| 边解释边执行 | 解释器 | 虚拟机 |
| "共享内存" | **编造词**，规范名是仓库/黑板 | — |

   质量属性联动：可扩展→事件驱动；可复用可测试→管道-过滤器；无确定解法→黑板。缺点三连：事件驱动难预测控制流、层次结构性能开销大、管道-过滤器不宜交互。
7. **OOA/OOD 流程对**（31/63，两套流程勿混）：
   - OOA 四步（31）：**概念类定骨架→关系连结构→职责分任务→交互图看协作**；
   - OOD 用例实现三步（63⚑）：**分类（提取边界/控制/实体三型类）→交互（构造交互图=顺序/通信图）→精化（根据交互图精化类图）**，口诀"分类—交互—精化"。答题先对齐题干空位序号，别被眼熟选项带走。
8. **微服务 vs SOA**（32）：三关键——粒度（细/粗）、通信（轻量 REST/ESB）、数据（独立库/共享库）。"六个独立"：开发/部署/运行/选型/伸缩/演化。

> - 盈亏平衡（第10章）：**Q\* = F / [P×(1−可变成本率−税率)]**；成本效益分析 NPV=Σ(CI−CO)ₜ/(1+i)ᵗ、投资回收期、**沉没成本不予考虑**；可行性四维（经济/技术/法律/用户使用）——【62⚑】依据
> - 决策五准则（乐观/悲观/折中/等可能/后悔值）与一次指数平滑在第2章展开

| 题 | 通式要点 |
| --- | --- |
| 29 图论选址 | 场景翻译表："连通所有点且总长最小"=**MST**（Kruskal 升序选边、成环即弃、选满 n−1 条）；"离最远点最短"=**图的中心**（逐点求偏心距 e(v)=max d(v,u)，取 min）；"到所有点总距离最短"=图重心（min-sum）。最短路要比"直达 vs 绕行" |
| 61 贝叶斯 | 口诀"**后验 ∝ 先验 × 似然**"——列先验（产量占比）×似然（次品率）直接比乘积，分母（全概率）同约。陷阱：只看似然（次品率高≠最可能来源）。方向：全概率=由因求果，贝叶斯=由果溯因 |
| 62⚑ 盈亏平衡 | **Q\* = F / [P×(1−可变成本率−税率)]**。三步军规：①把可变成本**总额折算成比率**（÷销售收入）；②税率随销售额变，**与可变成本同伙**一起扣；③单位口径统一后代入。去年销量常是干扰项 |

# 第三部分 一题带一类：六大题型通式库（融汇贯通核心）

> 把 63 题压缩成 6 个"通式 + 军规"。考场上先识别题型，再套通式。

## 通式一：计算题军规（覆盖 03/05/06/19/26/27/28/29/51/61/62）

```
① 定口径：把所有"字面数"先折算成公式需要的形态
   - 容量类：4KB 必写 2¹²；混合盘取最小盘；可变成本总额折成比率
   - 概率类：后验 ∝ 先验 × 似然
   - 位宽类：总位数先减符号位；十六进制 1 位 = 二进制 4 位
② 套通式：从下表对号取公式
③ 回代验算：构造一个"必须成立"的等式自检
   - 分页：页号×页大小+偏移 = 原地址；实地址 < 主存容量
   - RAID：结果 ≤ 裸容量，且为最小容量整数倍
   - 可靠性：结果在 [单件可靠度, 1] 之间，越并越好
   - 盈亏：边际贡献必为正，保本量 ≥ 0
```

| 题簇 | 通式 | 验算锚点 |
| --- | --- | --- |
| 缓冲区 | 单缓冲 R+S；双缓冲 max(R,S+P)；T=首块+(n−1)×瓶颈+尾部 | 首末块完整耗时别丢 |
| 分页 | 2^k → 砍低 k/4 位十六进制 → 高位即页号 | 回代还原原地址 |
| 浮点 | 移码阶码 [−2^p, 2^p−1]；补码尾数 [−1, 1−2⁻ⁿ] | 补码负界是 −1 |
| 可靠性 | 并联 1−(1−R)ⁿ；串联相乘 | (1−R³) 是"全失效"，与答案互补 |
| RAID | (N−1)×C，C 取最小盘 | 为最小容量整数倍 |
| 盈亏平衡 | Q\*=F/[P(1−v−t)] | 边际贡献>0 |
| 贝叶斯 | 比较先验×似然乘积 | 分母全概率可约去 |
| 乘法模型 | 总数=每单位上限×单位数（63×1023） | 漏乘/错加都是干扰项 |

## 通式六：PV/死锁/同步题（覆盖 04/42/09）

```
变量名一律先翻译成语义（available≡empty, data≡full），再看名字
三信号量模型：P(empty)→P(mutex)→临界区→V(mutex)→V(full)
铁律：同步 P 在互斥 P 前（否则死锁）；mutex 成对紧包；empty+full=N 恒成立
死锁四条件：互斥（不可破坏）+请求保持+不可剥夺+循环等待，防死锁=破坏后三条之一
```
