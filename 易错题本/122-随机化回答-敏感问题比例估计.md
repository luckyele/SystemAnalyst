# 备考笔记：随机化回答-敏感问题比例估计

## 一、题目
> 某学校希望通过问卷调查了解学生考试作弊的真实情况。若直接在问卷调查中问："你作弊了吗？"，极少有人真实做答。为此，专家设计的问卷调查表中包括两个问题：①你是男生吗？②你作弊了吗？每个学生需要利用自己配发的电子随机选题器选择一题并回答"是"或"否"。学校按照学生实际的男女比例，随机选择了 60 名男生和 40 名女生参与匿名答题，而电子随机选题器选择题 1 和题 2 的概率相同。学生们认为，此次调查不但匿名，还不透露自己选择了哪题，因此都如实做答。最后，学校回收到 35 份回答"是"，65 份回答"否"，因此计算出考试作弊的比例大致为__(59)__。
> A.10%
> B.15%
> C.20%
> D.25%

**答案：A. 10%**

## 二、知识点：随机化回答-敏感问题比例估计

### 1. 核心原理
这是**敏感问题调查的随机化回答技术（Warner 模型）**：为消除被调查者对敏感问题（作弊、吸毒、逃税等）的抵触，把**敏感问题与一个无关的是非问题**（如性别）混合，由随机器等概率二选一作答。调查者只知道"是/否"的总数，不知道每个人答的是哪题，从而获得真实回答。

"是"的总比例由两部分构成：**选到无关问题且答"是"的确定部分** + **选到敏感问题且为真（作弊）的未知部分**。用全概率公式即可反解出敏感比例。

### 2. 关键公式/规则
| 名称 | 表达式 |
| --- | --- |
| 全概率公式（答"是"） | P(是) = P·π + (1−P)·p |
| 反解敏感比例 | p = [P(是) − P·π] / (1−P) |
| 符号含义 | P = 选中敏感题的概率（本题 0.5）；π = 无关问题"是"的概率（男生占比 60/100 = 0.6）；p = 敏感特征比例（作弊率） |

### 3. 解题步骤
1. 算出答"是"的总体频率：35/100 = 0.35。
2. 确定两个分量：选题①与选题②概率各 0.5；男生占比 π = 60/100 = 0.6。
3. 列全概率方程：0.35 = 0.5×0.6 + 0.5×p。
4. 解得 p = (0.35 − 0.30)/0.5 = 0.10，即作弊比例约 **10%**，选 A。

## 三、易错点
1. **忘记无关问题的贡献**：直接把 35% 当成作弊比例（选 D.25% 也常是误把"是"减去某个错误基数）。必须先扣除"选到题①且是男生"的 0.5×0.6 = 0.30。
2. **除数搞错**：解出 0.35 − 0.30 = 0.05 后忘记再除以选题②的概率 0.5，得到 5% 而误判无答案。
3. **π 取错**：男生占比应按**抽样比例** 60/100 = 0.6 计算，而不是想当然的 0.5。
4. **题意误读**：题问的是"作弊比例"，不是"答'是'的比例"，也不是"男生作弊比例"。

## 四、扩展延伸
- **Warner 原始模型（1965）**：两道题都围绕敏感属性（"我属于 A"/"我不属于 A"），以概率 P 和 1−P 随机选择；本题是其**改进形式（无关问题模型 / Simmons 模型）**，用一个无风险问题替代另一半敏感问题，精度更高。
- **一般化变形**：若选敏感题概率为 P ≠ 0.5，公式 p = [λ − (1−P)·π] / P，其中 λ 为"是"的总频率。P 越接近 1，估计越准但保护性越差——**精度与隐私保护存在权衡**。
- **现实类比**：统计逃税率、出轨率、代驾酒驾率等敏感社会指标时常用此法；也出现在信息系统项目中"匿名满意度调查"的设计里。
- **关联考点**：全概率公式、贝叶斯公式（见笔记 61-贝叶斯公式-次品来源概率比较），都属于"由总量反推分量"的概率应用。
