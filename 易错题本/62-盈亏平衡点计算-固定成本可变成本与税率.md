# 备考笔记：盈亏平衡点计算-固定成本、可变成本与税率

## 一、题目

> 某厂生产的某种电视机，销售价为每台 2500 元，去年的总销售量为 25000 台，固定成本总额为 250 万元，可变成本总额为 4000 万元，税率为 16%，则该产品年销售量的盈亏平衡点为（  ）台（只有在年销售量超过它时才能盈利）。
>
> A. 5000
>
> B. 10000
>
> C. 15000
>
> D. 20000

**答案：A. 5000 台**

解析：盈亏平衡点（保本点、零利润点）是**全部销售收入等于全部成本（含税负）时的产量**。解题关键在于先把**可变成本率**与**税率**都折算成"随销量同比例变化"的比率：

- 去年总营收：25000 × 2500 = 6250 万元
- 可变成本率：4000 ÷ 6250 = 64%（即每台 2500×64% = 1600 元）
- 税率：16%（税虽不算成本，但**随销售额正比增长**，性质上等同变动项）

设盈亏平衡产量为 X 台，令"收入 = 固定成本 + 可变成本 + 税金"：

$$X\cdot2500 = 2{,}500{,}000 + X\cdot2500\times64\% + X\cdot2500\times16\%$$

整理得 $X\cdot2500\times(1-64\%-16\%) = 2{,}500{,}000$，即 $X\cdot2500\times20\% = 2{,}500{,}000$，$X\cdot500 = 2{,}500{,}000$，故 **X = 5000 台**，选 **A**。

本次误选 C（15000 台），是把成本与税率的口径折算错导致的估算偏差，需牢记"**可变成本率与税率都必须按销售额比例扣除**"。

## 二、知识点：盈亏平衡点计算

### 1. 核心原理

**盈亏平衡点（BEP，Break-Even Point）**：利润为零时的产销量，也称**保本点、零利润点**。低于它亏损，高于它盈利。

**量本利（CVP）基本关系**：

$$\text{利润} = \text{销售收入} - \text{可变成本} - \text{固定成本} - \text{税金}$$

- **固定成本**：不随产量变化（厂房折旧、管理人员工资等）。
- **可变成本**：随产量正比变化（原材料、计件工资等），通常用**可变成本率**（占销售额比例）或单位可变成本表示。
- **税金**：按销售额比例征收，**随销量正比变化**，因此在保本分析中与可变成本同性质处理。

### 2. 关键公式/规则

| 名称 | 公式 | 本题取值 |
| --- | --- | --- |
| 销售收入 | $R=P\times Q$ | 2500 × 25000 = 6250 万元 |
| 可变成本率 | $v = \dfrac{\text{可变成本总额}}{\text{销售收入}}$ | 4000 ÷ 6250 = **64%** |
| 单位可变成本 | $c = P\times v$ | 2500×64% = 1600 元/台 |
| 单位边际贡献 | $m = P\times(1-v-t)$ | 2500×20% = 500 元/台 |
| 盈亏平衡产量 | $Q^* = \dfrac{F}{P\times(1-v-t)} = \dfrac{F}{m}$ | 2,500,000 ÷ 500 = **5000 台** |
| 保本销售额 | $R^* = Q^*\times P$ | 5000×2500 = 1250 万元 |

其中 $F$ 为固定成本总额，$t$ 为税率，$P$ 为单价。

> **一句话记法**：盈亏平衡产量 = 固定成本 ÷ 单位边际贡献；单位边际贡献 = 单价 × (1 − 可变成本率 − 税率)。

含税与不含税的两种等价写法（结果一致）：

$$Q^* = \frac{F}{P(1-t)-c} = \frac{F}{P(1-t-v)}$$

### 3. 解题步骤

1. 先求**销售收入**（单价 × 销量），再据此把可变成本总额折成**可变成本率**：4000 ÷ 6250 = 64%。
2. 明确**税率也是变动项**：与可变成本一样按销售额比例随销量变化。
3. 写**保本方程**：X·单价 = 固定成本 + X·单价×可变成本率 + X·单价×税率。
4. 提取公因子得**单位边际贡献**：2500×(1−64%−16%) = 2500×20% = 500 元/台。
5. 固定成本 ÷ 单位边际贡献 = 2,500,000 ÷ 500 = **5000 台**，选 A。

## 三、易错点

1. **漏掉税率**（本题主要坑）：税随销售额增长，属变动项，必须与可变成本一起从边际贡献中扣除，不能当成固定成本或直接忽略。
2. **把可变成本总额当单位可变成本**：4000 万元是**总额**，须先除以销售收入得到 64% 的比率，或除以销量得 1600 元/台。
3. **比率折算方向搞反**：边际贡献率 = 1 − 可变成本率 − 税率 = 1 − 64% − 16% = 20%，不要算成 64% 或 80%。
4. **单位不统一**：固定成本用"元"（250 万 = 2,500,000 元），销售收入用"万元"，混用会差一万倍；建议统一成"元"或"万元"。
5. **把去年销量代入求保值**：25000 台是去年的实际销量，是干扰项；要求的是保本产量 X，二者不能混。
6. **误把利润公式写成"收入 − 成本"却忘记税**：税不是成本但同样减少利润，保本分析必须计入。

## 四、扩展延伸

- **边际贡献（Contribution Margin）**：$m = P(1-t-v)$，反映每卖一台对回收固定成本的贡献；固定成本一旦被贡献填平，余下即为利润。
- **安全边际**：安全边际量 = 实际销量 − 保本销量 = 25000 − 5000 = 20000 台，越大越抗风险。
- **利润验算**：按保本点 5000 台计算，收入 1250 万元，可变成本 800 万元（64%），税 200 万元（16%），固定成本 250 万元，利润恰为 0，验证无误。
- **现实类比**：把固定成本想成"每月必交的房租"，单位边际贡献想成"每做一单净落下的钱"；要做满 5000 单才刚够交房租，第 5001 单起才是真正赚的。
