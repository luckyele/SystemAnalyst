# 备考笔记：用户体验五层模型-层次与设计目标

## 一、题目
> 人机交互设计的用户体验五层模型从底层到顶层依次解决不同维度的问题，形成从抽象目标到具体实现的完整设计路径。以下是每层的核心设计目标及说明：
> 1. 战略层：最底层，决定产品的"根本性方向"。设计目标：明确用户需求和定义产品目标。
> 2. 范围层：基于战略层，明确产品的"具体功能边界"。设计目标：功能需求梳理和内容需求定义。
> 3. 结构层：规划产品的"逻辑架构"，解决"如何组织功能与内容"。设计目标：交互逻辑设计和信息架构设计。
> 4. 框架层：将逻辑架构转化为"界面布局方案"，解决"元素的空间排布"。设计目标：界面布局设计、导航设计、信息交互设计。
> 5. 表现层：最顶层，关注产品的"视觉呈现与感官体验"。设计目标：视觉设计、动效与反馈设计和感官体验优化。

（本条为知识点陈述型素材，常以"某设计活动属于哪一层"或"层次排序正误判断"的单选形式命题）

**答案：自底向上依次为 战略层 → 范围层 → 结构层 → 框架层 → 表现层（Strategy → Scope → Structure → Skeleton → Surface），方向为"从抽象目标到具体实现"**

## 二、知识点：用户体验五层模型（Garrett 五要素）

### 1. 核心原理
用户体验五层模型把产品设计拆成五个自下而上逐层依赖的层次：下层决定上层，上层实现下层。底层回答"为什么做"，越往上越回答"具体长什么样"。命题核心是**层次顺序**与**设计活动归属**两个维度。

### 2. 关键公式/规则
| 层次（自底向上） | 图示语言（关键词） | 设计目标 |
| --- | --- | --- |
| 1. 战略层 | 根本性方向 | 明确用户需求、定义产品目标 |
| 2. 范围层 | 具体功能边界 | 功能需求梳理、内容需求定义 |
| 3. 结构层 | 逻辑架构（如何组织功能与内容） | 交互逻辑设计、信息架构设计 |
| 4. 框架层 | 界面布局方案（元素的空间排布） | 界面布局设计、导航设计、信息交互设计 |
| 5. 表现层 | 视觉呈现与感官体验 | 视觉设计、动效与反馈设计、感官体验优化 |

### 3. 解题步骤（关键词锚定法）
1. 抓住题干设计活动的核心动词，问一句"它在回答什么"：
   - 为什么做、给谁做 → **战略层**
   - 做哪些功能、放哪些内容 → **范围层**
   - 怎么组织、流程怎么走 → **结构层**
   - 元素摆在哪里、怎么导航 → **框架层**
   - 视觉、动效、感官感受 → **表现层**
2. 见到"导航设计"直接锚定**框架层**（高频陷阱：易被误归入结构层）。
3. 见到"信息架构"锚定**结构层**；"界面布局"锚定**框架层**，两者一字之差分属两层。
4. 排序题先定两端：最底是战略层，最顶是表现层，再排中间三层的"范围 → 结构 → 框架"递进关系。

## 三、易错点
1. **方向反置**：命题人常问"从顶层到底层"或把选项顺序倒排。牢记：战略在最底，表现在最顶，自底向上是"从抽象到具体"。
2. **结构层与框架层混淆**：结构层是抽象的"逻辑架构"（交互逻辑、信息架构，不落到具体页面）；框架层是具体的"界面布局方案"（落到元素的空间排布）。判断标准：是否涉及具体页面上的摆放。
3. **范围层与结构层混淆**：范围层管"做什么"（功能与内容的边界清单）；结构层管"怎么组织"（流程与架构）。"梳理功能清单"属范围层，"设计操作流程"属结构层。
4. **导航设计归属**：导航设计在框架层，不属于结构层，也不属于表现层。
5. **表现层窄化**：表现层不只是"配色好看"，还包括动效与反馈设计、感官体验优化。

## 四、扩展延伸
- 该模型出自 Jesse James Garrett《用户体验要素》（The Elements of User Experience）。原书按"产品是否含超文本"分双维度：功能型产品侧依次为用户需求/产品目标、功能规格、交互设计、界面设计、感知设计；信息型产品侧依次为内容需求、信息架构、导航设计等。考题一般采用合并后的五层口径（即本题图示口径）。
- 与笔记 81「人机界面-黄金三原则」区分：黄金三原则（用户掌控、减轻记忆负担、一致性）是**设计原则**；五层模型是**分层设计路径/方法论**。两者常同场出现，注意题干问"原则"还是"层次"。
- 场景化命题举例：'为APP规划信息架构' → 结构层；'绘制页面线框图/原型' → 框架层；'确定目标用户画像与产品定位' → 战略层；'编写功能规格说明' → 范围层；'设计按钮点击反馈动效' → 表现层。
- 记忆口诀：**战范结框表**（战犯劫皇表），下定上、抽象到具体。
