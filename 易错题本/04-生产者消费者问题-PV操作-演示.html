5两条顺序铁律

✓ 正确顺序

P(empty) → P(mutex) → 放入 → V(mutex) → V(full)
P(full) → P(mutex) → 取出 → V(mutex) → V(empty)
同步信号量的 P 排在互斥 P 之前；同步信号量的 V 排在互斥 V 之后。

✗ 顺序颠倒 → 死锁

P(mutex) → P(empty) ...
若缓冲区已满，生产者会抱着 mutex 去等 empty；消费者又拿不到 mutex 去取数据，双方互相等待，形成循环等待 → 死锁。
生产者：P(empty) 占一个空位 → P(mutex) 进临界区 → 放入 → V(mutex) 出临界区 → V(full) 通知「有数据」
消费者：P(full) 等一个数据 → P(mutex) 进临界区 → 取出 → V(mutex) 出临界区 → V(empty) 归还空位
不变式：empty + full = N（P 减一、V 加一，恒等式可用于自查答案是否写反）
